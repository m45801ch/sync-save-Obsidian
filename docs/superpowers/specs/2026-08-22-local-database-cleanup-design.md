# 整理本地資料庫設計

## 目標

新增「整理本地資料庫」同步模式。選取此模式並按下同步後，只掃描本地 Vault 內的檔案，不連線、不上傳、不下載，也不修改雲端資料。

## 行為規則

1. 掃描 Vault 根目錄下所有檔案，包含任意深度的子資料夾；資料夾本身不列入檢查。
2. 以檔名（basename）判斷重複，不以完整相對路徑判斷。
3. 同名檔案中，只要有一個檔案位於 `public/` 或其子資料夾，就把 `public/` 路徑下的檔案移至既有本機回收桶設定。
4. 非 `public/` 路徑的檔案永遠保留；不因同名而互相覆寫或刪除。
5. `public/` 內沒有其他路徑同名檔時，不移動檔案。
6. 回收桶動作使用 `trashLocal` 或 `trashSystem`，不使用永久刪除。

## 介面

在既有同步方向下拉選單新增「整理本地資料庫（僅本機）」選項。選擇後沿用同步按鈕與既有進度/摘要顯示，完成摘要包含掃描數量、成功數量、失敗數量與移入回收桶數量。

## 架構

新增純函式掃描器，輸入本地相對檔案路徑，輸出應移入回收桶的 `public/` 路徑。`SyncService` 在此模式中跳過 provider connect、plan、manifest 與 cloud actions，直接執行掃描器輸出並回報摘要。既有同步模式維持原本行為。

## 驗證

- 純函式測試：遞迴路徑、basename 重複、只清理 public、沒有重複不清理。
- 服務測試：本機模式不呼叫 provider，移動 public 檔案並保留分類檔。
- 回歸測試：既有同步測試全部通過，TypeScript build 成功。
